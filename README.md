## Aim
To design and implement a Car Mileage Calculator using Flutter Forms, `TextFormField`, input widgets, and `StatefulWidget`, validate user inputs, and dynamically display the calculated mileage.

---

## Features
- **Form Validation:** Validates required fields, numeric formats, and positive values using `GlobalKey<FormState>`.
- **Dynamic State Updates:** Updates UI with real-time mileage results and efficiency evaluations (`Poor Efficiency`, `Average Efficiency`, or `Excellent Efficiency`) via `setState()`.
- **Responsive Form Design:** Features custom text field decorations, input prefixes/suffixes, and scrollable structure.
